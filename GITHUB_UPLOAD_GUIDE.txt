MONKEY AI — GITHUB UPLOAD GUIDE

IMPORTANT:
- Upload the contents of this folder to the ROOT of your GitHub repository.
- Do NOT upload .env files containing real secrets.
- Do NOT upload dist/ or .git/.
- Keep .env.example; it is only a template.

PROJECT ROOT:
  package.json
  package-lock.json
  tsconfig.json
  vite.config.js
  index.html
  .env.example
  .gitignore
  README.md
  src/

The entire src/ folder must stay together with its internal folders/files.

GITHUB WEBSITE METHOD:
1. Create a new EMPTY GitHub repository, e.g. monkey-ai.
2. Open the repository.
3. Click Add file -> Upload files.
4. From this folder, upload the ROOT files listed above.
5. Upload the complete src/ folder while preserving its folder structure.
6. Click Commit changes.

DO NOT upload:
  dist/
  .git/
  node_modules/
  .env
  .env.local
  .env.production

RENDER NOTE:
This package is currently the frontend project. The secure backend/model-router/JSONBin integration still needs to be implemented before a full production AI deployment.

ADMIN SECURITY:
The example file contains a placeholder admin password only. Never put a real production password or API keys into GitHub.
